# Проверки сборки Premium Update

Дата: 26 октября 2026. Node.js 24.22.1.

## Автоматические проверки

`npm test`: **9 тестов, 9 пройдено, 0 ошибок**.

Проверены:

1. Регистрация, повторный email, неверный пароль, межустройственный вход, CORS, недоступность серверных файлов, удаление старого авторского API и телефон вместо ссылки авторских вариантов.
2. Бесплатный первый тест, гостевой доступ, два бесплатных урока. В закрытом каталоге нет подборок платных тестов и полных текстов закрытых уроков. Платные API возвращают 403; подмена интерфейса их не открывает.
3. Создание ручного заказа с суммой и сроком с сервера, идемпотентность повторного заказа, запрет самостоятельной активации, недоступность чужих заказов, однократная активация владельцем.
4. Полная попытка из четырёх модулей, 98 результатов, серверная проверка ответов, запрет раннего получения ключей и вопросов других модулей, адаптивная ветка, перерыв, повторный запрос завершения, удаление выбранного ответа и межустройственное продолжение.
5. Урок → новые задания из каталога внешнего банка → разбор → причина ошибки → жалоба → статистика. Повторение 1/3/7/14, отсутствие повышения после одного ответа, отсутствие повышения при досрочной практике, сброс после ошибки, отсутствие дублей при повторной отправке.
6. Истечение подписки закрывает ранее созданные платные попытки и уроки; бесплатный первый тест остаётся доступен.
7. Имитации Payme callbacks: авторизация, неверная сумма, повторный ID, конкурентные подтверждения, одинаковое время повторной операции, отсутствие двойного продления, отмена, таймаут 12 часов, CheckTransaction и GetStatement. Это локальное тестирование протокола, не подтверждение готовности реальной кассы.
8. Аддитивный перенос пользователей и сессий v1 SQLite, сохранение исходных SQL-таблиц, повторный запуск без дублирования.
9. Локальная демонстрация оплаты, отмена, продление, отсутствие повторного начисления и отказ при чужом заказе. Демонстрационный режим запрещён при NODE_ENV=production.

Задания в автоматических тестах — намеренно искусственные временные fixtures с маркировкой TEST FIXTURE. Они нужны для проверки логики и не выдаются за задания SAT, не входят в публичный контент и не используются в обычном запуске.

## Дополнительные проверки

- `node --check` для файлов JavaScript в `public/`, `server/` и `scripts/` — без ошибок.
- Сборка `npm run pages` с тестовым адресом API прошла. В выходной папке только 16 публичных файлов, без `.env`, серверных уроков, ответов и приватного каталога. Тестовая сборка `dist/` в поставляемый архив не включена; её нужно пересобрать с настоящим адресом своего API.
- Драйвер MongoDB установлен и импортируется. Подключение к настоящему кластеру пользователя не проверялось: реквизиты не предоставлены. Интеграционные тесты хранилища выполнялись с SQLite.
- Прямые запросы из исполнительного окружения получили HTTP 200 от внешнего вопросного сервиса; проверена нормализация реальных заданий Reading & Writing и Math. Тексты этих заданий не сохранялись в поставляемый архив.
- В браузерном предпросмотре проверены главная страница с исходным дизайном, номер телефона, замки Premium, бесплатный запуск, страница тарифа и переключение на узбекский язык.
- Внешние задания в браузерном предпросмотре вернули QUESTION_SOURCE_UNAVAILABLE, хотя отдельные прямые запросы к источнику прошли. Поэтому полный браузерный экзамен с живыми вопросами в этом окружении **не подтверждён**; перед приёмом денег нужно проверить доступность источника с собственного Render-сервера.
- Авторизованные экраны и платежи проверены через HTTP-интеграционные тесты; полный браузерный вход и реальные покупки не выполнялись. Мобильная CSS-адаптация сохранена и расширена, отдельная проверка на реальном телефоне не выполнялась.

## Перед реальным платным запуском

Нужны настройки своей MongoDB, развёртывание API, проверка внешнего банка с Render и подключение/тестирование кассы Payme, если нужен автоматический приём денег. В поставляемой конфигурации включены заказы с ручным подтверждением владельцем. Есть шесть готовых уроков; полного курса и полного перевода внешних разборов нет. Восстановление пароля и подтверждение почты не реализованы.
